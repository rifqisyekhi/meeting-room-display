# Sistem Booking Ruang Rapat - Admin

Prototype frontend berbasis HTML, CSS, dan JavaScript vanilla.

## Fitur
- Login admin tanpa Google
- Dashboard admin
- Manajemen rapat
  - Tambah rapat
  - Edit rapat
  - Hapus rapat
  - Lihat/detail rapat
  - Filter: semua, berjalan, segera, selesai, akan datang
  - Search dan filter ruangan/status
- Manajemen ruangan
  - Tambah/edit ruangan
  - Status tersedia/terpakai/perbaikan
  - Fasilitas dan kapasitas
- Manajemen pengguna
  - Tambah/edit/hapus pengguna
  - Role dan status
  - Search/filter
- Kalender
- Laporan
- Pengaturan
- Responsive desktop/tablet/mobile

## Menjalankan
1. Extract ZIP.
2. Buka folder di VS Code.
3. Buka `index.html`.
4. Cara paling mudah: install extension VS Code "Live Server", lalu klik kanan `index.html` > Open with Live Server.

## Catatan
Data saat ini tersimpan di memori browser selama halaman aktif. Belum ada backend/database.
Untuk sistem produksi, JavaScript frontend perlu dihubungkan ke API/backend dan database seperti MySQL/PostgreSQL.
